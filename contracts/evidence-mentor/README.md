# Evidence Mentor contracts

These schemas are the cross-repository truth boundary for the private research MVP.

- `pathlab.ai-pack/1` describes a locally installed expert pack and its rights/resource gates.
- `pathlab.ai-evidence/1` is the immutable, signed, slide-bound result accepted by Viewer.
- `pathlab.knowledge-pack/1` contains reviewed atomic claims; the tutor may select claim IDs but may not invent factual prose.
- `pathlab.model-qualification-report/1` records checksum-bound synthetic or held-out checks without activating a pack.

Raw WSI pixels and reusable embeddings are never valid evidence-bundle members. All contracts are research-only and fail closed.
