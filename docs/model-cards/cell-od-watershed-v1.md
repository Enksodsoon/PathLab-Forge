# Optical-density cell fallback

Status: `experimental`. This deterministic CPU fallback applies bounded optical-
density thresholding, distance-transform markers, watershed instance separation,
and reviewed-region RLE masks. It passes the executable synthetic touching-nuclei,
repeatability, and mask checks. It must nevertheless run only as a
`qualification-<hex>` job and must not be activated for staff/demo evidence until
tissue-diverse instance accuracy, morphometry distributions, and failure-rate
gates pass on rights-cleared held-out fixtures.

Reported counts, area, perimeter, eccentricity, and solidity are descriptive
pixel measurements. They are not clinical cell identities, tumor labels, or a
diagnostic result. No learned cell-type prediction is performed.

The executable synthetic protocol is documented in
`docs/evidence/brightfield-qualification-protocol-v1.md`. Its current terminal
status remains `experimental`; synthetic checks are not qualification evidence.
