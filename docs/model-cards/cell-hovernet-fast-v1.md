# HoVer-Net fast cell pack

Status: `not-evaluable`. No weights are bundled or installed by Forge. The code and weights have
separate license entries; PanNuke-derived weights are private, non-redistributed research inputs.
Qualification requires patient/source-held-out instance PQ, count error, morphometry bias,
cross-tissue failure rate, deterministic repeats, and the declared RAM/VRAM envelope. Predicted
types remain research categories and are not clinical cell identities.
