# Evidence

Do not commit sensitive local slide files.

Record sanitized evidence for:

- operating-system and architecture;
- application and dependency versions;
- reader selected;
- source format, size and dimensions;
- companion-file count;
- crop/downsample/render preset;
- elapsed conversion time;
- peak memory where measurable;
- OME-TIFF, DZI and package size;
- upload/import/preview result;
- known limitation.

Store sensitive local evidence outside Git or under ignored `docs/evidence/local/`.
