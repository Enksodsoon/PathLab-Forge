# Brush composition

Brush Add/Subtract edits one explicitly selected closed ROI on its saved series, Z, T and view revision. It does not create a separate subtract ROI or assign historical strokes to a parent. Historical `brush_add` polygons remain valid independent ROIs. Historical standalone `brush_subtract` annotations remain stored but are rejected as analysis ROIs.

The parent retains its ID, hierarchy, labels and style. `AnnotationRepository.composeBrush(datasetId, parentId, expectedRevision, operation, strokeGeometry, series, z, t, viewRevision)` performs a synchronized, atomic property-file update, changes the type to `roi_mask`, and increments its revision. Wrong scope, stale revision, zero-area strokes, unchanged results, empty results and interrupted work are rejected before writing.

The geometry is `mask/1|x,y;x,y;...|x,y;x,y;...`, with an even-odd fill rule. Each contour has at least three vertices. Limits are 64 contours, 2,048 total vertices, 65,536 characters and finite nonnegative coordinates within signed integer source dimensions. A brush stroke has at most 1,024 vertices. Gesture capture cancels at its limit; it does not silently truncate the committed region.

Java's existing `java.awt.geom.Area` performs union/subtraction. Its curve boundaries, including Java's cubic ellipse representation, are flattened at 0.01 source-pixel tolerance when the composite is serialized. The stored polygon contours thereafter define the mask, its area, its perimeter and pixel inclusion. Anisotropic calibration scales each segment in X/Y independently. No physical units are emitted without valid calibration.

The renderer uses separate closed contours and SVG even-odd filling. Vertex and whole-object editing preserve contour boundaries. Crop export intersects the actual area with the crop and scales its contours, preserving holes and disconnected regions. Analysis snapshots retain the exact encoded mask, parent revision, plane/view, mask format and flattening tolerance; a later composition invalidates acceptance of previous or running analyses.

`SlideViewer.onComposeBrush(parentId, operation, strokeGeometry, expectedRevision)` carries the revision captured by the gesture. The root HTTP handler must recheck current dataset/view and requested source dimensions, then call the repository method with this revision. Use `MaskContours.parse`/`shape` to validate every contour against source bounds; do not split this encoding as a legacy single polygon. The deterministic tool selector must include `roi_mask` and exclude standalone subtract strokes.

Private result metadata preserves the complete `roi_mask` contours with `format: mask/1` and `fillRule: evenodd`. The legacy Viewer annotation contract currently rejects interior rings. Its batch route must fail closed for this type rather than silently filling holes. Viewer overlay rendering of this metadata is a separate qualification requirement.

Local verification (2026-10-08): the full Java suite passed (313 tests, 9 existing real-reader fixture skips), all 87 frontend tests passed, and the TypeScript/production bundle budget passed. Tests cover real subtraction holes, disjoint additions, anisotropic measurements, persisted reload, clipped exports, exact analysis pixel inclusion, stale running/completed runs, cancellation, invalid scope/CAS, degenerate/unchanged/empty operations and complexity limits. The 1,025-vertex stress case reproduced a recursive whole-path regex stack overflow; bounded per-vertex validation fixes it. These are local deterministic fixture and component checks; actual native desktop gesture/pixel qualification and Viewer mask overlays remain separate evidence.
